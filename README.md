# 🚀 TM | اپلیکیشن مدیریت کارها، گزارش‌های روزانه و تعاملات

اپلیکیشن استندالون تحت وب به زبان فارسی جهت مدیریت تسک‌ها، ثبت گزارش‌های کارکرد روزانه، و ثبت و پیگیری تعاملات کاری با افراد و سازمان‌ها.

---

## 📁 دیتابیس محلی (Local Folder Database)
تمام داده‌های شما در پوشه‌ی **`data/`** در کنار خود پروژه ذخیره می‌شود:
- `data/database.json`: فایل اصلی دیتابیس شامل تمام تسک‌ها، گزارش‌ها و تعاملات.
- **پشتیبان‌گیری بسیار ساده**: برای بک‌آپ‌گیری فقط کافیست پوشه‌ی `data/` یا فایل `database.json` را کپی کنید.

---

## ⚡ نحوه راه‌اندازی و اجرا

### روش اول (با اسکریپت ویندوز - یک کلیک):
فایل **`start.bat`** را اجرا کنید. برنامه خودکار وابستگی‌ها را نصب کرده و مرورگر را در آدرس `http://localhost:3000` باز می‌کند.

### روش دوم (از طریق ترمینال):
```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای برنامه
npm start
```
سپس در مرورگر خود آدرس زیر را وارد کنید:
```
http://localhost:3000
```

## ✨ امکانات اصلی

1. **✅ مدیریت تسک‌ها (Tasks)**
   - تعریف تسک با اولویت (کم، متوسط، بالا، فوری 🔥)
   - تعیین سررسید شمسی و دسته‌بندی/پروژه
   - تغییر وضعیت سریع (انجام نشده / در حال انجام / تکمیل شده)
   - فیلتر بر اساس اولویت، وضعیت و جستجوی متنی

2. **📝 گزارش روزانه (Daily Reports)**
   - ثبت خلاصه کارها، دستاوردها، چالش‌ها و برنامه روز بعد
   - تاریخ‌گذاری شمسی خودکار
   - امتیازدهی به عملکرد روزانه (۱ تا ۵ ستاره)

3. **🤝 ثبت تعاملات و پیگیری‌ها (Interactions & CRM)**
   - ثبت تماس‌ها، جلسات، پیام‌ها، ایمیل‌ها و دیدارهای حضوری
   - یادداشت‌برداری نکات جلسه
   - تعیین تاریخ پیگیری و تغییر سریع وضعیت پیگیری

4. **📊 داشبورد و آمار**
   - مشاهده خلاصه‌ی وضعیت تسک‌های باز، کارهای فوری و پیگیری‌های معوقه
